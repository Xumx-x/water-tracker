# 💧 喝了么 — 喝水追踪器

一个轻量、美观、零依赖的每日饮水追踪工具。纯 HTML 单文件，双击即用，支持多用户登录与数据隔离，内置后台管理面板。

---

## ✨ 功能一览

### 🔐 用户系统

- **登录**：打开页面弹出登录框，输入用户名即可进入
- **自动创建**：首次输入用户名自动注册，无需额外操作
- **会话缓存**：同设备下次打开自动登录，无需重复输入（等效于按设备/IP 缓存）
- **登出**：右上角 ⏻ 按钮一键登出，回到登录界面
- **数据隔离**：每个用户只能看到自己的喝水数据，互不干扰

### 快速记录

- 四种预设容量一键记录：小杯 150ml / 标准杯 250ml / 大杯 400ml / 水瓶 500ml
- 自定义毫升数输入，回车即可添加
- 每条记录自动标注当前时间
- 卡片右上角「📅 补录历史」入口

### 今日进度

- 环形进度图实时展示今日饮水量 / 目标 / 完成百分比
- 达成目标自动弹出庆祝提示 🎉
- 显示完成度、剩余量、记录次数

### 每日目标

- 默认 2000ml，支持 +/− 每次调整 100ml
- 范围限制 500ml ~ 10000ml
- 位于右列顶部，醒目易调

### 今日记录管理

- 按时间倒序排列，显示杯子图标 + 时间 + 毫升数
- 内联编辑：点击 ✎ 按钮直接修改毫升数，Enter 保存 / Esc 取消
- 单条删除：点击 ✕ 按钮移除
- 一键清空今日（带确认弹窗，防误删）

### 近 7 天趋势

- 柱状图展示最近一周每日饮水量
- 今日柱条高亮显示，达标日显示绿色
- 位于右列，与日历上下排列

### 📅 当月日历视图

- 日历网格展示当月每天的饮水量
- 颜色分级：灰色（无记录）/ 蓝色（有记录）/ 浅绿（过半）/ 深绿（达标）
- 月份切换：‹ 上月 / 今月 / 下月 ›
- 月度统计：本月合计 / 记录天数 / 日均饮水 / 达标天数
- 点击任意历史日期直接打开补录弹窗
- 今日高亮显示，未来日期半透明不可点击
- 底部图例说明颜色含义

### 历史记录查看

- 按天折叠显示，点击日期行展开/收起当天具体记录
- 分页浏览：默认每页 10 天，支持切换 10 / 20 / 50 条/页
- 页码可编辑跳转，支持上一页/下一页
- 时间范围筛选：
  - 最近一周 / 最近一月（默认）/ 最近三月 / 全部 / 自定义日期范围
- 每天显示日期、记录条数、总饮水量、是否达标

### 历史日期补录

- 快速记录卡片右上角「📅 补录历史」按钮
- 弹窗可选择任意历史日期和时间进行补录
- 不可选择未来日期
- 实时预览所选日期已有记录和合计
- 历史记录弹窗展开某天后，底部可直接「＋ 为这天补录」
- 日历视图中点击任意历史日期也可直接补录

### 数据管理

- **自动保存**：所有记录自动存入浏览器 localStorage，关闭页面不丢失
- **📤 导出（用户级）**：一键下载当前用户数据为 `water-data.js` 备份文件
- **📥 导入（用户级）**：选择备份文件后自动加载数据到当前登录用户
- **📤📤 全量导出（管理员）**：后台一键打包**所有用户**的完整数据为 JSON 备份文件（文件名带时间戳）
- **📥📥 全量导入（管理员）**：从备份文件恢复所有用户数据，导入前带预览确认，防止误覆盖

### 🛠 后台管理

- 登录页面底部「🛠 进入后台管理」入口
- 密码验证（密码：`water123`）
- **汇总统计**：注册用户数、总记录条数、总记录天数、总饮水量
- **近 7 天日活用户柱状图**：统计每天有饮水记录的用户数，今日高亮
- **用户列表表格**：
  - 头像、用户名、记录条数、记录天数、总饮水量、每日目标
  - 首次登录时间、最后活跃时间
  - 按最后活跃时间降序排列
  - 每行支持 🗑 删除用户（带二次确认弹窗）
- 删除用户将永久清除该用户的所有数据和注册记录
- **全量数据备份**：
  - 「📤 导出全部数据」：将所有注册用户及其完整数据打包成一个 JSON 文件，文件名格式 `water-backup-all-<时间戳>.json`
  - 「📥 导入全部数据」：选择备份文件后先弹出预览确认框（显示导出时间、用户数、每用户目标与记录天数），确认后覆盖写入
  - 导入会**替换当前所有用户数据**，请谨慎操作
  - 导入后自动刷新前台（当前登录用户数据同步）和后台面板统计

## 🛠️ 技术实现

### 用户数据隔离策略

```
用户打开页面
  → 检查 localStorage 中的 session（会话缓存）
    → 有缓存 → 自动登录该用户
    → 无缓存 → 显示登录框
      → 输入用户名
        → 已注册 → 直接登录
        → 未注册 → 自动创建账号 → 登录
  → 登录后加载该用户专属数据
  → 所有读写操作绑定到当前用户的 localStorage key
```

### localStorage Key 设计

| Key | 作用 |
|-----|------|
| `water_tracker_session` | 当前登录用户名（会话缓存） |
| `water_tracker_users` | 所有已注册用户名列表（JSON 数组） |
| `water_tracker_user_<用户名>` | 该用户的喝水数据 |

### 用户数据结构

```json
{
  "_goal": 2000,
  "_firstLogin": "2026-08-19T14:30:00.000Z",
  "_lastActive": "2026-08-19T14:51:00.000Z",
  "2026-08-10": [
    { "time": "09:30", "amount": 250, "id": 1723456789 },
    { "time": "14:15", "amount": 400, "id": 1723456790 }
  ],
  "2026-08-09": [
    { "time": "08:00", "amount": 500, "id": 1723456788 }
  ]
}
```

- `_goal`：每日饮水目标（毫升）
- `_firstLogin`：首次登录时间（ISO 时间戳）
- `_lastActive`：最后活跃时间（ISO 时间戳）
- 日期键（`YYYY-MM-DD`）：当天的记录数组
- 每条记录：`time`（时分）、`amount`（毫升）、`id`（唯一标识，时间戳）

### 后台管理安全说明

- 后台密码硬编码在页面中（`water123`），仅用于前端展示层面的简单访问控制
- 纯前端方案无法实现真正的服务端鉴权，如需高安全性请配合后端服务使用
- 后台可查看所有用户的统计数据和登录时间，可删除用户

## 📋 使用流程

### 首次使用

1. 双击 `water-tracker.html` 打开
2. 输入用户名，点击「进入」
3. 开始记录喝水，数据自动保存

### 日常使用

1. 打开页面（同设备自动登录，无需再输入用户名）
2. 喝水后点击对应容量按钮记录
3. 随时查看进度环、趋势图、日历和历史记录
4. 需要切换用户时点击右上角 ⏻ 登出

### 数据备份与迁移

**单用户备份**：
1. 点击右上角 **📤** 导出当前用户数据为 `water-data.js`
2. 保存到安全位置作为备份
3. 换设备时：在新设备登录后点击 **📥** 导入备份文件

**全量备份（管理员）**：
1. 进入后台管理，点击「📤 导出全部数据」
2. 得到包含所有用户的 JSON 备份文件（文件名带时间戳）
3. 恢复时进入后台点击「📥 导入全部数据」，预览确认后完成恢复

### 补录历史数据

1. 点击「📅 补录历史」按钮，或点击日历中的任意历史日期
2. 选择日期和时间
3. 点击快速按钮或输入自定义毫升数
4. 也可以在历史记录弹窗中展开某天后直接补录

### 后台管理

1. 在登录页面点击「🛠 进入后台管理」
2. 输入密码 `water123`
3. 查看所有用户统计、日活图表
4. 如需删除用户，点击对应用户行的 🗑 按钮
5. 如需整体备份/恢复，使用「📤 导出全部数据」/「📥 导入全部数据」
