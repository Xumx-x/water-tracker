# 💧 喝了么 — 喝水追踪器

一个轻量、美观、零依赖的每日饮水追踪工具。纯 HTML 单文件，双击即用，发给任何人都能直接打开。

---

## ✨ 功能一览

### 快速记录
- 四种预设容量一键记录：小杯 150ml / 标准杯 250ml / 大杯 400ml / 水瓶 500ml
- 自定义毫升数输入，回车即可添加
- 每条记录自动标注当前时间

### 今日进度
- 环形进度图实时展示今日饮水量 / 目标 / 完成百分比
- 达成目标自动弹出庆祝提示 🎉
- 显示完成度、剩余量、记录次数

### 每日目标
- 默认 2000ml，支持 +/− 每次调整 100ml
- 范围限制 500ml ~ 10000ml
- 位于右列顶部，醒目易调

### 今日记录管理
- 按时间倒序排列，显示杯子图标 + 时间 + 毫升数
- 内联编辑：点击 ✎ 按钮直接修改毫升数，Enter 保存 / Esc 取消
- 单条删除：点击 ✕ 按钮移除
- 一键清空今日（带确认弹窗，防误删）

### 近 7 天趋势
- 柱状图展示最近一周每日饮水量
- 今日柱条高亮显示，达标日显示绿色
- 位于右列，与日历上下排列

### 📅 当月日历视图
- 日历网格展示当月每天的饮水量
- 颜色分级：灰色（无记录）/ 蓝色（有记录）/ 浅绿（过半）/ 深绿（达标）
- 月份切换：‹ 上月 / 今月 / 下月 ›
- 月度统计：本月合计 / 记录天数 / 日均饮水 / 达标天数
- 点击任意历史日期直接打开补录弹窗
- 今日高亮显示，未来日期半透明不可点击
- 底部图例说明颜色含义

### 历史记录查看
- 按天折叠显示，点击日期行展开/收起当天具体记录
- 分页浏览：默认每页 10 天，支持切换 10 / 20 / 50 条/页
- 页码可编辑跳转，支持上一页/下一页
- 时间范围筛选：
  - 最近一周 / 最近一月（默认）/ 最近三月 / 全部 / 自定义日期范围
- 每天显示日期、记录条数、总饮水量、是否达标

### 历史日期补录
- 快速记录卡片右上角「📅 补录历史」按钮
- 弹窗可选择任意历史日期和时间进行补录
- 不可选择未来日期
- 实时预览所选日期已有记录和合计
- 历史记录弹窗展开某天后，底部可直接「＋ 为这天补录」
- 日历视图中点击任意历史日期也可直接补录

### 数据管理
- **自动保存**：所有记录自动存入浏览器 localStorage，关闭页面不丢失
- **自动加载**：页面打开时通过 `<script>` 标签自动读取同目录下的 `water-data.js`
- **📤 导出**：一键下载 `water-data.js` 备份文件
- **📥 导入**：选择备份文件后自动加载数据并覆盖 `water-data.js`
- 数据优先级：localStorage（最新）> water-data.js（首次访问回退）

- 宽度 > 860px：双列并排

## 📁 文件说明

| 文件 | 说明 | 是否必须 |
|------|------|----------|
| `water-tracker.html` | 应用本体，双击打开即用 | ✅ 必须 |
| `water-data.js` | 数据文件，首次打开自动加载；导出/导入时自动覆盖 | 推荐 |
| `server.js` | 早期版本的 Node.js 本地服务器（已弃用，单文件版本不需要） | ❌ 不需要 |

### 交付方式

将 `water-tracker.html` 和 `water-data.js` 两个文件放在**同一目录**下，双击 HTML 文件即可在浏览器中打开使用。发给别人时两个文件一起发送即可。

## 🛠️ 技术实现

### 数据存储策略

```
页面加载 → 读取 localStorage（有数据直接用）
         → localStorage 为空 → 读取 water-data.js（首次访问）
         → 都没有 → 返回空对象

每次记录 → 写入 localStorage + 更新内存中的 __WATER_DATA__
导入文件 → 写入 localStorage + 下载覆盖 water-data.js
导出文件 → 下载当前数据为 water-data.js
```

### 为什么数据文件是 .js 而不是 .json

浏览器在 `file://` 协议下会阻止 `fetch/XHR` 读取本地 `.json` 文件（CORS 限制），但 `<script>` 标签没有这个限制。因此数据文件写成 JS 格式：

```javascript
window.__WATER_DATA__ = {
  "_goal": 2000,
  "2026-08-10": [
    { "time": "16:35", "amount": 500, "id": 1786350909048 }
  ]
};
```

通过 `<script src="water-data.js">` 自动加载执行，导入时兼容 `.js` 和 `.json` 两种格式。

### 数据结构

```json
{
  "_goal": 2000,
  "2026-08-10": [
    { "time": "09:30", "amount": 250, "id": 1723456789 },
    { "time": "14:15", "amount": 400, "id": 1723456790 }
  ],
  "2026-08-09": [
    { "time": "08:00", "amount": 500, "id": 1723456788 }
  ]
}
```

- `_goal`：每日饮水目标（毫升）
- 日期键（`YYYY-MM-DD`）：当天的记录数组
- 每条记录：`time`（时分）、`amount`（毫升）、`id`（唯一标识，时间戳）

## 📋 使用流程

### 日常使用

1. 双击 `water-tracker.html` 打开
2. 喝水后点击对应容量按钮记录
3. 数据自动保存，关闭页面也不丢失
4. 随时查看进度环、趋势图、日历和历史记录

### 数据备份与迁移

1. 点击右上角 **📤** 导出 `water-data.js`
2. 将文件保存到同一目录覆盖旧文件，或保存到其他位置作为备份
3. 换设备时：将 `water-data.js` 放到新设备同一目录，或点击 **📥** 导入

### 补录历史数据

1. 点击「📅 补录历史」按钮，或点击日历中的任意历史日期
2. 选择日期和时间
3. 点击快速按钮或输入自定义毫升数
4. 也可以在历史记录弹窗中展开某天后直接补录
